# UFOlding from <img src="https://github.com/user-attachments/assets/87119fb5-c39d-429a-9bfd-424f0e100720" alt="" width="30px"> PropJockey

Silly nonsense that made me smile.

Adds code folding for 🛸 to 🐄 comments.

Alternatively, 👽 can be used instead of 🐄.

## Install

```
curl -L -o ufolding-0.0.1.vsix "https://raw.githubusercontent.com/propjockey/UFOlding/main/ufolding-0.0.1.vsix" && code --install-extension ufolding-0.0.1.vsix
```

## Usage

Unfolded:

```js
// 🛸 Custom code folding
const doSomething = () => {
  console.log("propjockey.io")
}
// 🐄
```

Folded:

```js
// 🛸 Custom code folding
// 🐄
```

Comments fold to matching indentation and can be nested.
